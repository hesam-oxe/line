# ✦ لاین نوری استار — Linenory-Star

دموی سینمایی سه‌بعدی وب‌سایت فروش و اجرای **لاین نوری LED** — فارسی، RTL، تم تیره لوکس.

> 🌐 **پیش‌نمایش زنده:** https://hesam-oxe.github.io/line/

## ✨ امکانات

| بخش | توضیح |
|------|-------|
| 🌌 هیرو سه‌بعدی | خطوط نور شناور + ذرات پارالکس با **Three.js** و افکت **Bloom** |
| 🎬 حرکت دوربین | با اسکرول کاربر، دوربین در صحنه سه‌بعدی حرکت می‌کند |
| ⚡ شبیه‌ساز نور | تغییر زنده دمای رنگ (۶۵۰۰K / ۴۵۰۰K / ۳۰۰۰K / RGB) + اسلایدر شدت نور |
| 🃏 Glassmorphism | کارت‌های شیشه‌ای با هاور نورانی |
| 🔢 شمارنده متحرک | آمار با اعداد فارسی و انیمیشن |
| 🖼 لایت‌باکس | گالری نمونه‌کار با ناوبری کیبورد |
| 📱 موبایل‌اول | کاملاً ریسپانسیو + منوی کشویی |
| 💬 واتساپ | فرم مشاوره و دکمه استعلام قیمت → پیام آماده واتساپ |

## 🛠 تکنولوژی

- HTML5 + CSS3 + JavaScript خالص (بدون فریم‌ورک)
- [Three.js 0.160](https://threejs.org/) — صحنه‌های سه‌بعدی با `UnrealBloomPass`
- [GSAP 3 + ScrollTrigger](https://gsap.com/) — انیمیشن‌های اسکرول سینمایی
- فونت [وزیرمتن](https://fonts.google.com/specimen/Vazirmatn)
- تصاویر: Unsplash

## 🚀 اجرا

به‌دلیل استفاده از ES Modules، فایل را با یک سرور محلی باز کنید:

```bash
# مثال با پایتون
python -m http.server 8080
# سپس: http://localhost:8080
```

## 📂 ساختار

```
line/
├── index.html          ← تک‌صفحه کامل (۹ بخش)
├── css/
│   ├── base.css        ← متغیرها، هدر، هیرو، دکمه‌ها
│   └── sections.css    ← شبیه‌ساز، کارت‌ها، گالری، فوتر، ریسپانسیو
└── js/
    ├── three-scene.js  ← صحنه هیرو + شبیه‌ساز (WebGL + Bloom)
    └── main.js         ← GSAP، منو، شمارنده، لایت‌باکس، فرم
```

## ⚙️ شخصی‌سازی

- شماره واتساپ: متغیر `WHATSAPP` در `js/main.js` (فعلاً نمونه است)
- رنگ سازمانی: متغیرهای `--gold / --cyan / --violet` در `css/base.css`
- تصاویر: لینک‌های Unsplash در `index.html`
